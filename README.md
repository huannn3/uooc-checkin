# Uooc 自动签到

基于 **JavaScript / Node.js、Playwright 和 Microsoft Edge** 的 Windows 签到助手，用于每天进入已配置的 Uooc 课程并核实签到结果。支持多门课程、每日定时、登录 Windows 后自动打开助手、签到次数显示及登录失效提醒。

当前源码及本地版本为 v1.3.0，已将自动登录接入签到掉登后的恢复流程；下方已发布的 v1.1.2 便携包仍使用手动登录。

## 下载与使用

**Windows 下载：** [便携包（v1.1.2）](https://github.com/huannn3/uooc-checkin/releases/download/v1.1.2/UoocCheckin-v1.1.2-win-x64.zip)。[版本说明与校验文件](https://github.com/huannn3/uooc-checkin/releases/tag/v1.1.2)。

请下载上述 Windows ZIP，完整解压后双击 `launch.vbs`；GitHub 的 Source code 压缩包仅供源码维护。

便携包适用于 64 位 Windows 10/11，附带 Node.js 和 Playwright，电脑需已安装 Microsoft Edge。无需安装 Codex、Node.js 或运行 npm。

将压缩包完整解压到固定目录，双击 `launch.vbs`。先点“登录 / 添加课程”，在 Edge 中自行登录、完成验证码并逐个进入课程，保存成功后关闭配置用的 Edge 窗口。然后点击“立即签到”，成功后再按需启用每日定时。详细步骤见 `快速开始.txt`。

分发包不含任何个人登录状态、课程配置、浏览器数据或日志。首次打开不会自动启用定时任务；启用后请勿移动或删除程序目录，需要移动时先关闭定时，移动完成后重新启用。反馈问题时提供版本、Windows/Edge 版本和错误提示，勿发送登录状态文件或浏览器数据。

自启动仅在当前用户登录 Windows 后打开助手，每日签到按设定时间执行；首次打开不会自动启用自启动。

v1.1.1 修复新签到成功后仍保存昨日次数的问题：新签到后最多查询成绩接口 6 次，间隔逐步延长，合计等待约 15.5 秒（不含网络请求时间）。同时核实当天记录与已知的昨日次数；网站仍未同步时显示“待同步”，保留网站实际返回的次数，不自行加一。界面读取缓存时允许替换文件；写入遇到临时占用会重试，持续占用只记录提示，继续签到其余课程。

次数读取 `/home/course/progress` 的 `signin_cnt` 与 `signin_total`；它是老师设定的满分次数，未必是课程要求的全部出勤次数。次数显示来自最近一次运行，不是实时刷新；查询失败显示“暂不可用”，已确认的新签到仍保留成功结果。重新登录和会话恢复未验证成功时保留原凭据，网络错误不会直接当成登录失效。程序保存登录状态，但不能保证网站会话永久有效。

从旧版升级：关闭旧助手，等待签到或配置结束，将新版解压后的程序文件复制到原来的程序目录，覆盖同名程序文件，保留所有个人文件，不删除原目录。这样已有登录和定时任务仍使用原路径。

## 项目语言与原理

- **JavaScript / Node.js**：读取课程配置、启动浏览器、保存登录状态和核实签到结果。
- **Playwright + Edge**：首次配置时由用户手动登录、完成验证码；日常运行恢复已保存的会话并进入课程页面。
- **PowerShell + WinForms**：提供图形界面，并管理 Windows 每日定时和登录后的自启动任务。
- **VBScript**：通过 `launch.vbs` 启动助手，隐藏命令行窗口。

网站在进入课程学习界面时执行签到。助手等待课程信息接口返回，根据 `is_sign` 和成绩接口的 `signin_time` 核实当天是否签到，并读取 `signin_cnt` / `signin_total` 显示次数。新签到后会短暂重查成绩接口，以处理签到确认和次数更新之间的延迟。

登录会话保存在本机 `.uooc-auth.json`，包括 Cookie 和网页存储，运行时用于恢复会话；配置窗口使用独立的 `.uooc-profile` 浏览器目录。默认可以在 Edge 中手动输入账号密码；也支持通过“登录账号设置”在本机保存账号，后续登录时由 Playwright 自动填写。鼠标会平滑移至验证框并点击一次，未通过时提示本人手动处理，不重复点击，也不自动处理进一步的验证题。登录凭据属于敏感数据，不要分享已配置过的整个目录；分发时使用原始 ZIP。

可选账号保存在 `.uooc-login.dat`，使用 Windows DPAPI 加密，限定当前 Windows 用户恢复。它不上传到 GitHub，也不放入分发包；同一用户权限下的程序仍可能读取，不能将加密理解为绝对安全。更换电脑或 Windows 用户后请重新设置。点击“清除已存账号”仅删除自动填写所用的账号密码，保留已有登录会话和课程。

## 登录可能失效

**保存过登录状态不代表永久登录，第二天失效也有可能。** Cookie 或服务端会话到期、网站撤销会话等情况都可能导致需要重新登录；本程序不能延长网站规定的会话有效期。

明确检测到登录失效时，如果已通过“登录账号设置”保存可用账号，助手会打开临时的普通 Edge 窗口，自动填写账密并尝试点击验证框一次。网站确认登录、新会话在签到浏览器恢复且再次核实成功后，才替换登录快照并继续处理课程。该流程同时用于“立即签到”和每日定时，覆盖签到前及处理课程途中掉登；每次运行最多尝试重新登录一次，再次掉登时停止并提醒。

验证框尝试一次后仍未通过时可在临时窗口手动处理；自动恢复等待验证通过最多约 30 秒（页面加载及登录核实另有超时），结束后关闭该临时窗口。未配置账号、登录失败或恢复失败时，助手保留原登录快照并停止剩余课程；后台定时签到仍会弹窗提醒。按提示点击“登录 / 添加课程”重新登录，关闭配置用 Edge 后再点“立即签到”即可。已有课程和定时设置保留。502、网络超时等错误本身不会触发自动登录。

如果某门课程签到已确认，但查询次数时才掉登，恢复成功后继续其余课程；该课程仍显示签到成功，次数在下次签到检查时刷新。

活动记录保存在本地 `uooc.log`，最终签到次数以课程成绩页为准。

Uooc [官方帮助](https://www.uooc.net.cn/misc/support)说明：登录学习界面会自动签到，每天一次；达到老师设定的满分次数后不再增加。本脚本只进入课程首页，不操作视频、测验或讨论。

## 窗口入口

双击桌面上的 **Uooc 签到助手**，或者此目录中的 `launch.vbs`，即可打开窗口，不用输入命令。

- **立即签到**：用已保存的登录状态处理全部课程，活动区域实时显示结果。
- **登录 / 添加课程**：打开配置用 Edge，手动登录并逐个进入课程，完成后关闭配置窗口。
- **登录账号设置**（v1.3.0）：可选保存本机加密账号密码。“登录 / 添加课程”及签到掉登后的恢复都会使用它。已有会话有效时直接沿用；需要登录时自动填写并尝试点击验证框一次。只在网站显示“验证通过”且登录按钮可用时提交；未通过时提示你手动处理。保存账号本身不会验证密码是否正确。每日定时优先恢复已有会话，明确掉登后尝试自动重新登录一次；未能恢复时提醒你重新登录。
- **每日签到时间**：选择时间，点击“保存 / 启用定时”；要停用时点“关闭定时”。
- **签到时显示浏览器窗口**：勾选可查看实际运行页面，不勾选则后台运行。
- **移除选中课程**：只从自动签到清单移除，不会在网站退课。
- **启用开机自启动 / 关闭自启动**：管理当前用户登录 Windows 后自动打开助手的独立任务，不改变每日签到时间。
- **已签 / 满分需**：显示最近查询到的签到次数，例如 `3 / 30`。初次配置后需运行一次签到查询；标“旧”表示本次尚未核实缓存结果，标“待同步”表示签到已确认、网站成绩次数仍未同步。

课程名称会在下一次成功签到检查后自动显示。现有登录和课程配置直接沿用。定时任务也在后台运行，不弹出命令行窗口。第一次打开窗口不会自动安装定时任务。

## 第一次使用

1. 完整解压下载的 Windows ZIP，双击 `launch.vbs` 打开助手。
2. 点击“登录 / 添加课程”，在打开的 Edge 窗口中手动登录并完成验证码。
3. 在网站中逐个进入需要签到的课程学习页面，助手会记录课程。
4. 等活动记录提示登录状态已保存，再关闭配置用的 Edge 窗口。
5. 点击“立即签到”，确认所有课程成功后，再按需启用每日定时。

首次配置进入课程时，也可能触发当天签到。日常使用直接点击“立即签到”；需要查看运行页面时，勾选“签到时显示浏览器窗口”。

## 每日定时运行（Windows）

在助手中选择“每日签到时间”，点击“保存 / 启用定时”。更改时间后再次保存即可，停用时点击“关闭定时”。

时间使用 Windows 系统时区。电脑需要开机且当前用户已登录；错过时间后会在可用时补跑，不能补签往日记录，也不会自动唤醒电脑。程序只管理当前目录的任务；有另一份程序时，请在原目录管理原任务。

如需登录 Windows 后自动打开助手，点击“启用开机自启动”；停用时点击“关闭自启动”。自启动只打开助手，每日签到仍按设定时间执行。

活动记录分别显示“今日签到成功”“今日已签到”或“签到次数已满”。当天重复运行不会额外增加次数，最终以课程成绩页为准。

## 登录失效、增删课程

登录失效或需要增加课程时，点击“登录 / 添加课程”，在配置用 Edge 中登录并进入需要记录的课程，保存后关闭该窗口。验证码需要手动完成；如果失败，请查看网站提示并检查网络。

移除课程时，在助手的课程列表中选中课程，点击“移除选中课程”。这只修改自动签到清单，不会在网站退课。

配置期间请先完成登录并关闭配置窗口，再运行签到。不要分享 `.uooc-profile`、`.uooc-auth.json` 或 `.uooc-login.dat`，它们包含登录凭据；个人配置、浏览器数据、日志、状态缓存和本地备份均已加入 Git 忽略规则。

## 源码开发与验证

需要 Edge、Node.js 20+ 和 Playwright。便携包已附带运行环境，`run.ps1` 优先使用包内 `runtime/node.exe`。源码目录也支持系统 Node.js 和这台电脑 Codex 提供的运行时。仅复制源码到其他电脑时，安装 Node.js 后在此目录执行 `npm install`（使用已安装的 Edge，无需下载 Chromium）。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 test
```

测试检查地址校验、响应监听顺序、签到与次数结果、成绩延迟同步、缓存占用重试及界面刷新、登录失效与网络错误区分、后台提醒触发、原凭据保护、中文编码和开机自启动。还覆盖签到前及途中掉登后的恢复、每次最多一次重新登录、继续剩余课程、再次掉登停止、验证失败、密码错误、502、会话恢复失败及快照保存失败。测试使用模拟账户和定时接口，在独立临时目录验证，不会创建真实任务或修改真实登录数据。实际账户的签到结果需要首次登录后验证；平台更新接口或页面流程时，脚本会报错而不会自行声称成功。
