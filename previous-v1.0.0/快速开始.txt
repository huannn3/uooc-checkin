Uooc 签到助手 v1.0.0 — 朋友测试版

使用条件：64 位 Windows 10/11，已安装 Microsoft Edge，可以正常访问 Uooc。
本包已附带运行环境，无需安装 Codex、Node.js 或其他开发工具。

第一次使用
1. 将压缩包完整解压到一个固定目录，例如 D:\Uooc签到助手。
   不要直接在压缩包里运行，也不要只复制 launch.vbs。
2. 双击 launch.vbs，打开“Uooc 签到助手”。
3. 点击“登录 / 添加课程”，在打开的 Edge 窗口自行登录并完成验证码。
4. 逐个进入想签到的课程学习页面；助手会记录课程。
5. 确认活动记录提示已保存登录状态后，关闭配置用的所有 Edge 窗口。
6. 点击“立即签到”，确认所有课程成功。
7. 需要自动签到时，选择每日时间，再点击“保存 / 启用定时”。

日常使用
- 定时运行需要电脑开机且用户已登录，使用 Windows 系统时区，不会自动唤醒电脑。
- 当天重复运行可能显示“今日已签到”，签到次数以网站成绩页为准。
- 登录失效时，重新点击“登录 / 添加课程”。
- 只进入课程并核实签到，不操作视频、测验或讨论。
- 程序只管理当前目录的定时任务；有另一份程序时，请在原目录先关闭定时。

移动或停用
启用定时后不要移动或删除程序目录。
需要移动时，先点击“关闭定时”，移动整个目录后再重新启用。
停用时先关闭定时，然后删除解压目录即可。

反馈问题
提供 v1.0.0、Windows/Edge 版本、所点按钮及错误截图。
截图请遮住姓名、账号和不想公开的课程信息。
不要发送 config.json、.uooc-auth.json、.uooc-profile 或完整日志。
这些个人文件在你首次配置后产生，原始分发包中不包含它们。

其他说明
首次打开不会启用定时任务；浏览器验证码需要本人手动完成。
如 Windows 阻止运行来自互联网的脚本，在确认来源后可查看压缩包的
“属性”，如有“解除锁定”选项，勾选后重新解压。无需关闭系统安全功能。
运行环境：Node.js v24.19.0（x64）、Playwright 1.62.1。
第三方许可证随包保留在 runtime 和 node_modules 目录中。
