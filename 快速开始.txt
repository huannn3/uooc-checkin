Uooc 签到助手 v1.3.0

使用条件：64 位 Windows 10/11，已安装 Microsoft Edge，可以正常访问 Uooc。
本包已附带运行环境，无需安装 Codex、Node.js 或其他开发工具。

项目简介
使用 JavaScript / Node.js 和 Playwright 驱动 Edge，PowerShell WinForms 提供窗口，
launch.vbs 提供无黑窗入口，Windows 任务计划程序负责每日定时和登录后的自启动。
Uooc 在进入课程学习界面时执行签到；助手恢复本地保存的登录会话，
逐个进入已配置课程，通过网站接口核实当天签到并读取签到次数。
程序只处理签到，不操作视频、测验或讨论。

第一次使用
1. 将压缩包完整解压到一个固定目录，例如 D:\Uooc签到助手。
   不要直接在压缩包里运行，也不要只复制 launch.vbs。
2. 双击 launch.vbs，打开“Uooc 签到助手”。
3. 点击“登录 / 添加课程”，在打开的 Edge 窗口自行登录并完成验证码。
4. 逐个进入想签到的课程学习页面；助手会记录课程。
5. 确认活动记录提示已保存登录状态后，关闭配置用的所有 Edge 窗口。
6. 点击“立即签到”，确认所有课程成功。
7. 需要自动签到时，选择每日时间，再点击“保存 / 启用定时”。
8. 需要开机自动打开助手时，点击“启用开机自启动”。

日常使用
- 可以点击“登录账号设置”，在本机加密保存账号密码；后续点击“登录 / 添加课程”会在需要登录时自动填写。
  鼠标会平滑移至网站验证框并点击一次；验证通过后自动提交登录，未通过时请手动处理。
  程序不会重复点击或自动处理进一步的验证题。已有有效会话直接沿用。
  “立即签到”和每日定时在明确掉登后会使用已保存账号，打开临时 Edge 并自动尝试重新登录一次。
  核实新会话恢复成功后继续签到；未配置账号、验证失败或恢复失败时仍会提醒你手动处理。
  临时窗口等待验证通过最多约 30 秒，页面加载及登录核实另有超时，结束后关闭临时窗口。
  保存账号不保证网站登录永久有效；502、网络超时等错误本身不会触发自动登录。
- “清除已存账号”仅清除自动填写所用的账号密码，不删除已保存的登录会话或课程。
- 定时运行需要电脑开机且用户已登录，使用 Windows 系统时区，不会自动唤醒电脑。
- 当天重复运行可能显示“今日已签到”，签到次数以网站成绩页为准。
- 登录失效时，重新点击“登录 / 添加课程”。
- 只进入课程并核实签到，不操作视频、测验或讨论。
- 程序只管理当前目录的定时任务；有另一份程序时，请在原目录先关闭定时。
- “已签 / 满分需”显示最近查询到的次数，例如 3 / 30。满分需是老师设定的满分次数。
- 次数查询失败显示“暂不可用”；标“旧”表示之前的次数本次尚未核实。
- 新签到后会短暂等待网站成绩次数同步。仍标“待同步”时，签到已确认，次数以成绩页为准。
- 显示缓存被临时占用时会自动重试，持续占用会记录提示并继续处理其余课程。
- 自动签到掉登后先尝试自动恢复一次；未完成时会弹窗提醒，按提示重新登录即可。
- 开机自启动在登录 Windows 后打开助手，每日签到仍按设定时间执行。

登录状态提醒
保存登录状态不代表永久登录，第二天失效也有可能。
Cookie 或服务端会话到期、网站撤销会话等情况可能导致需要重新登录。
助手明确检测到掉登后，使用已配置账号尝试自动重新登录一次，恢复成功后继续签到。
未完成或同一次运行再次掉登时，后台定时签到会弹窗并停止剩余课程。
点击“登录 / 添加课程”重新登录，关闭配置用 Edge 窗口，再点击“立即签到”。
原有课程及定时设置保留，不需要删除个人文件。网络错误不会直接判定为掉登。

升级
升级时，先关闭旧助手并等待任务结束，把新版全部文件复制到原程序目录，
覆盖同名程序文件，保留个人文件，不删除原目录，不另换路径。

移动或停用
启用定时后不要移动或删除程序目录。
需要移动时，先点击“关闭定时”和“关闭自启动”，移动整个目录后再重新启用。
停用时先关闭定时和自启动，然后删除解压目录即可。

反馈问题
提供 v1.3.0、Windows/Edge 版本、所点按钮及错误截图。
截图请遮住姓名、账号和不想公开的课程信息。
不要发送 config.json、.uooc-auth.json、.uooc-login.dat、.uooc-profile、.uooc-status.json、backups 或完整日志。
这些个人文件在你首次配置后产生，原始分发包中不包含它们。

其他说明
首次打开不会启用定时任务；自动点击未能通过验证时，需要本人手动完成。
如 Windows 阻止运行来自互联网的脚本，在确认来源后可查看压缩包的
“属性”，如有“解除锁定”选项，勾选后重新解压。无需关闭系统安全功能。
运行环境：Node.js v24.19.0（x64）、Playwright 1.62.1。
第三方许可证随包保留在 runtime 和 node_modules 目录中。
